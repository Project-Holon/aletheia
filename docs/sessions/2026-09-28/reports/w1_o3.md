## Near misses

- ov114 0x021CB764 BN_usub: code shape identical, 44 diff lines, a pure register
  permutation. Target: max r4, min r5, b r6, a r7, r r8, zero sb; this build places
  max/min in the top registers. Declaring `i` as `long` reaches 23 lines with only max
  and min swapped; declaration order (all 120 orders), `register`, a `dif` form and
  the OpenSSL `a->top < b->top` guard do not move it.
- ov114 0x021CC674 BN_gen_exp_string: 16 diff lines. Structure found (inner zero-skip
  loop with shared w recompute, `if (cnt >= 256) while (cnt >= 256)`). Residue: target
  keeps 0xff in fp (pushes r3/fp) where the build uses sl; target schedules
  `ldm {d, top}` after the two terminator byte stores; target sets `hi = 0` as `movle`
  after the compare. Declaration order was hill-climbed.
- ov009 0x021782B4 DWCi_Auth_Start: one instruction short (51 lines by shift). The
  target literal pool holds DWCauthhttpparam twice and loads the DWC_Http_Create
  argument from the second entry instead of reusing the base used for the
  .fc/.f10 stores. Struct copy, array, volatile, inline-wrapper and cast variants all
  fold to one load; every dsi compiler gives the same result (the object stamp,
  4.0.0.1025, has no build).
