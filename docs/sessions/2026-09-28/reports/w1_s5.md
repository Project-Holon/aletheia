## Idioms learned

- A tail `return 1` after a chain of `if (!call) return 0;` compiles to shared fail/succeed blocks only when written `if (!(a && b && c)) return 0; return 1;` (gsXml write functions). The early-return chain gives inline predicated returns instead. For a lone final call, `if (!call) return 0; return 1;` (not `!= 0`, not a ternary) reproduced the `cmp; moveq 0; movne 1` tail in gsXmlWriteHexBinaryElement.
- A 16-byte copy written as `*(struct { char c[16]; } *)dst = *(struct ...*)src` reproduces the 2-bytes-per-iteration `ldrb/strb` loop that memcpy() and an index loop do not (gsUdpEngineRemoveMsgHandler).
- DWARF locals are listed in reverse declaration order and declaration order fixes register assignment (gsXmlCountChildren, gsiXmlUtilWriteUnicodeString).
- `char x[4] = {0,0,0,0};` reproduces an `add r5,sp,#0` followed by four `strb` in the prologue.
- A relocation at `gTopScreen+0x5c0` resolves through `g_021AD1C8[736 + pos]`; no separate `g_021AD788` symbol is needed.
- Function-pointer table stores: the pool order follows source store order (ghttpSetRequestEncryptionEngine needed start before cleanup).
