# w8_o2: overlay SDK wave 8, lane Opus 2 (large rows, 1 KB and up)

Four rows were assigned. One is EXACT, two are parked in pending as near misses (DIFF), and
one was not started because the context budget ran out (about 150k). All are ARM. The
natneg.o, natify.o and mb_parent.o work used dsi/1.1p1, flags -O4,p, lang c99 (natneg.o and
natify.o are stamped 4.0.0.1025, mb_parent.o 4.0.0.1024). I tried 1.1, 1.2 and 1.2p1 on both
near misses. None of them helped, so the residue is in the source.

I opened no `.c` or `.h` under `sdk/` and ran no git commands. I worked from
`tools/sdkobj.py` (DWARF, `--types`, listing) and `match.py one`.

## Near misses

- **Think (natify.o), same size, residue is register choice only.** In the NN_ERTREPLY branch
  (+0x11C to +0x1C0), the object puts the inline memcpy loop counter in r3, the base of the
  got* flags (gotADDRESS1b) in r1 and porttype in r2. The draft puts them in sb, r3 and r1.
  The NN_ADDRESS_REPLY branch, which has the same copy shape, matches. Things tried with no
  effect: flag struct vs int array, switch vs if chain on porttype, all case orders,
  switch(ptype), local declaration order, the ptype spelling, and the compilers.
- **MBi_CommParentCallback (mb_parent.o), 4 bytes long.** Everything outside the
  fileid_of_child block of CHILD_DISCONNECTED matches, including both error-code jump tables.
  Inside that block, the object addresses the fileinfo[fileID] bitmaps as
  `(mbc + fileID*0x5D4) + 0x1D00` with an immediate offset. The draft folds the constant into
  mbc and uses `[base, idx]`, which costs one add over the three accesses. Things tried with
  no effect: fileID as u8/int/u16/u32/s8, a cast expression with no local, `&(...)->`,
  `(fileinfo + i)->`, `i[fileinfo]`, a static inline helper, an unused `nowChildFlag` load,
  element padding from 4 to 0x6C, and the compilers.

## Levers found

- **The enum compares unsigned in range tests (natneg.o).** NegotiateThink tests
  `state <= ns_initsent` and `state <= ns_preinitack` with `bhi`, but the house build uses
  `-enum int`, so an enum-typed field gives `bgt`. Casting the read to `(unsigned int)` matches.
  Equality tests are unaffected.
- **The receive loop is a do/while inside a guard (natneg.o).** The object tests
  `negotiateSock != -1` once outside and again at the bottom of the loop, with
  CanReceiveOnSocket at the top. That is
  `if (sock != -1) do { if (!CanReceive(sock)) break; ...; if (state == canceled) break; } while (sock != -1);`.
  A `while (a && b)` or a `while` with two breaks puts the test in the wrong place.
- **The natify Think loop is the opposite case.** It is a `while (sock != -1 && CanReceive(sock))`
  rotated with the test duplicated at the top. The source form that reproduces it is
  `if (a && b) do {...} while (a && b);`. A plain `while` enters through the bottom test.
- **Globals in the same .bss are addressed from one base (natify.o).** The seven got* flags
  are read as offsets from a single `gotADDRESS1b` literal, so they are extern'd as one struct
  at 0x021AE44C. Separate externs would give seven pool entries.
- **A block local that DWARF drops (mb_parent.o).** The object keeps `sparg->aid` in ip across
  the u16 stores of the fileid block. Without a `u16 child = sparg->aid;` copy the compiler
  reloads aid after every store (24 bytes long). DWARF lists only tmpCb, i and sparg.
- **Jump table extent shows explicit cases.** In the API_ERROR switch the table spans 0..15
  although only 1, 4, 5, 6, 8 and 9 differ from the default. An explicit `case 15:` is
  needed in the default group.
