The shared libc/string.h was not touched (two matched ov009/ov016 files declare memcmp themselves).

## Tooling note

sdkobj.py `member()` returns the first archive member with a given name; libdwcutil.TWL.HYB.a has two members named `scenesetusbready` (only the second defines cbUsb), so `sdkobj.py 0x021ce45c` reports "member not found". I used a scratch wrapper (scratchpad/w6_s6/sd.py, monkeypatching member() to pick the member that defines the symbol). tools/ not edited; fix belongs in member() (match on the defining symbol, not just the name).

## Near misses

- 0x021D0B44 DWCi_USBAPlBegin (372 B): 4 mismatching instructions plus pool. Target: `bl OS_GetTick; ldr r3,[MemUsb]; ...; ldr r0,[MemUsb]` before WM_Initialize (MemUsb reloaded after the tick call and the 64-bit start store). Ours loads MemUsb into r4 after the call and reuses it (`mov r0,r4`). Tried: direct `MemUsb->start = OS_GetTick()` (loads lhs base before the call), tick local (call first, but r4 cached), signed/unsigned long long, K&R prototype, `u32 start[2]` with u64 cast store, WM_Initialize with `->wmBuf` argument, no `rs` local. Everything else matches (struct copy of SCAN_PRM as struct assignment, second pool spelling `(void *)0x021DE654` for the HEAPlFree_ argument, TSKlForm(0, taskFirst, 0, 0x78)).
- 0x021D0E74 scanFirst (344 B): register allocation only. Target keeps `prm` on the stack (`str r0,[sp]` at entry, reloaded per iteration), i in fp, info in r7, j in r6 (first loop) and sl (second loop); ours keeps prm in fp, i in r5/r8. Tried: all six declaration orders of (info, i, j), one shared j vs a block-scoped j per loop. Control flow and instruction sequence agree.
- 0x021D1868 disp (396 B): 10 instructions in the tail after the button loop. Target loads C_WIN (same pool word 0x021DA9FE) into r4 and S_WIN into r2 before `cmp r3,#0xc0`, keeps `add r4,sp,#4` (&r) after; ours reuses r2 for both and computes the rest in a different order. Tried: `y1 = 0; y0 = y1;` (fixes the earlier movge order), sum operand order, clamp as ternary in the call, clamp as statement, a local `CoordT *cw`, second extern spelling (creates a second pool word, which the target does not have). First 0x128 bytes and the loop match.
