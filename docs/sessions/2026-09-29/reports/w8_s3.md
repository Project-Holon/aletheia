## Levers learned (for the levers list)

- `s += len; use s[0], s[1], s + 2` instead of `s[len]`, `s[len + 1]`, `s + len + 2` stops MWCC folding an
  earlier `s += 0x23` into every later use; it reproduced the vendor's materialised s (client_hello,
  rcv_server_hello).
- `do { p++; } while (*p)` behind an `if (*p)` guard reproduces the vendor's single guard (make_dn).
- `while (c2 = *pat++, c1 = *name++, c1 == c2) {...}` reproduces a loop entered in the middle (compare_fqdn).
- `if (m != 4 && m != 5) a; else b;` gives cmp/cmpne, whereas `m == 4 || m == 5` gives the sub/cmp #1 range trick.
- Declared-order register effects: purge_session needed `i`, `p`, `enabled` (enabled last) despite DWARF order.
- A hex-arithmetic year/day parse matches only as `s[0]*10 + s[1] - 528`, not `(s[0]-'0')*10 + ...`.
