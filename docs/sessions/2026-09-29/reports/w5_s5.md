## Levers found (new in this lane)

- Layout-determining shape of tests: a shared `return 1`/`return -1` in the image means the source has ONE `||` chain, not consecutive ifs (0x0216F0A0: `f62a == 1 || f629 == 1`; 0x0216B65C: `ctrl == 0 || IsError() || (state != 4 && state != 5)` all to one `mvn r0,#0` exit). Conversely a fall-through block placed after the dispatch means switch case order in the source differs from the compare order (0x021713CC: `case 1` before `case 0: case 2`, and the "bad" arm `sendCommand = 3` as the else of the positive test).
- 64-bit tick fields: `tick = OS_GetTick(); cnt->f = tick;` with a `u64` local is required, otherwise the compiler evaluates GetMatchCnt() before the tick call (0x02171E34, 0x02172604, 0x0216F0A0, 0x021713CC, 0x0217576C). The `OS_TicksToMilliSeconds` idiom is `((tick - old) * 64) / 33514 > 15000` on unsigned long long, which emits `_ll_udiv`; the symbols block must carry `_ll_udiv 0x0209C00C arm` (compiler helper as emitted) or one relocation stays unresolved and the verdict is MATCH, not EXACT.
- A shared tail in the image (0x0217576C, `bls` to the common `mov r0,#1`) is a `goto done` from the elapsed-time test rather than a second `return 1`.
- 0x02174ED0: the image has a load/store of the message's last word right after the first `MI_CpuCopy8`; only `*(volatile int *)&sbMsg.pid = sbMsg.pid;` reproduces it (plain self-assignment is dropped). Kept, and flagged: the real source construct is unknown.

A ternary in a call argument (`x ? A : B`) does not reproduce the literal order: an `if (x != 0) call(A) else call(B)` pair does.
