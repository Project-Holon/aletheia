## Levers found

- Local declaration order matters for register assignment beyond the reverse-of-listing rule: SEARCHlGetApInfo needed `num, i, ap` (permutation search found it), the plain reverse gave 11 differing bytes.
- Reading a byte table then `>> 1` as `((unsigned)s >> 1)` gives `lsr` where the plain int shift gives `asr` (setBar).
- A jump-table switch needs an explicit `case 0: break;` when the original table has a bx-lr entry for 0 in addition to the default bx lr (calcRect).
- Hoisting a repeated field load into a local (`int x = g->x;`) reproduces the single `ldrh ip` reused for both stores (calcRect).
- `if (rs != 2) return 0; return 1;` gives `movne #0 / moveq #1` order, `return rs == 2` gives the reverse (SEARCHlStop).
- `char *` string params compile to `ldrsb` under -char signed; the vendor used unsigned loads, so parameters are `unsigned char *` (STRlNLen, ConvertStringAsciiToUnicode). `bool` parameters are `unsigned char` (formTask alloc, ldrb from the stack).
- Switch arms in image order (5 then 4, default last) reproduce the callback shape in search.o.
- Data symbols in the `symbols:` block take the token `data` even for strings ("string" leaves the relocation unresolved).
- Struct layouts recovered: MemSb (scrollbar): cell 0, task 0xc, x/y u16 0x10/0x12, off 0x16, base 0x18, len 0x19, pos 0x1a, bar 0x1b, a 0x1c, b 0x1d; MemSearch (0x1e60): buf 0xf00, ap[20] stride 0x2a at 0x1300, scan param (0x44) at 0x1648, WMStatus at 0x168c, flag 0x1e5c; MemTask entry stride 0x40 (que 0, delque 4, list 8, first 0x10, head 0x20, count 0x34, flag 0x38); TCB {prev, next, func 8, work 0xc, prio 0x10, alloc 0x11}; MemSnd arc 0xa4, task 0xa8, handle 0xa0.
