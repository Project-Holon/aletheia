## Near miss

- 0x0218DD88 gpiFailedOpCallback: 60 bytes differ, and the size is right (908). Cases 0
  (0x20 bytes) and 2 (0x204 bytes) call memset in the object. Cases 1, 5, 4 and 6 zero
  with inline strb runs, which `__builtin__clear` reproduces. Case 3 (the 16-byte clear
  loop) is exact. The residue is only in the four strb-run cases:
  - The object schedules `ldr r0, [r7, #0x1c]` (operation->result) above the last clear
    strb, as if the byte stores could not alias it. It colours the load r0.
  - Ours keeps the load after the run in r1 and puts `mov r0, r8` first.

  What was tried:
  - naming the call memset (no dsi build inlines it);
  - clear on `(char *)arg`;
  - clear with `sizeof(*arg)`;
  - a result temp read before the clear (this hoists the load to the top);
  - a zero struct assignment;
  - dsi 1.2 through 1.6sp1 (1.2 to 1.3p1 give the same 60 bytes).

## Levers that closed rows (candidates for idiom pages)

- A field value that stays in a callee-saved register across a call is a named local.
  In both gpipeer.o functions, `str = peer->inputBuffer.buffer;` is reused after
  `*str = '\0'`, which gives the one load feeding strncmp and gpiValueForKey (0x0218E6DC
  and 0x0218E3B0).
- A jump table based one below the first real case means an empty `case 0x65: break;`
  (0x0218E3B0).
- GOAGetLastError is called with the socket (`ldr r0, [r8, #4]` before the bl), although
  the DWARF prototype says `(void)`. Declare it unprototyped and pass `data->sock`
  (0x021903B0).
- There are two return shapes for a boolean call result:
  - `return f(x) != 0;` gives `movne #1; add sp; moveq #0`.
  - `if (!f(x)) return 0; return 1;` gives a conditional return plus `mov r0, #1`, or
    `movne/moveq` before the `add sp` when the call ends the function (0x02196948,
    0x02196DC4).
- `magicString = (len > 2) && !memcmp(...);` as one expression swaps its register with
  actualMessage (r5/r4), where the if/else spelling does not. Moving either declaration
  above the other has the same effect (0x02196DC4).
- A socket address zeroed with two `str` inline is a `struct SOCSockAddrIn address =
  {0};` block local, declared just before its field stores (0x02198328, 0x021903B0).
- A byte-scan loop entered by `b` to the bottom `cmp j, #0x200` is the single
  `for (j = 0; (j < sizeof(buffer)) && ((c = str[j + 6]) != '\0') && (c != ','); j++)`.
  A body with `break` rotates the loop (0x02190188).
- `CHECK_RESULT`-style `{ int __result__ = f(); if (__result__ != 0) return __result__; }`
  blocks match the DWARF `__result__` locals directly.

## Tooling note

When a command is passed through the Bash tool, `\\` in a quoted heredoc reaches Python as a
single backslash, so `'\\0'` in a Python replace string became a NUL byte and the
replacements silently did nothing. Use the Edit tool, or avoid backslashes, when you
script source edits.
