## Levers found

- **volatile on one struct field (NHTTPi_ThreadRecvHeaderProc).** The object stores `res_p->headerLen` and reloads it from the same slot before the zero test. Every non-volatile spelling tried (about 12: reading through `req_p->res_p`, else arms, ternary, pointer alias, sub-expression order) forwards the stored register and drops the `ldr` (456 bytes, or 464 with a second `req_p->res_p` load). Declaring `NHTTPRes.headerLen` as `volatile int` gives 460 bytes EXACT. The header carries a `note:`. The DWARF has a plain int. Last resort per the brief.
- **memset for a 4-byte zero of a local array.** `char tmpBuf[4]` zeroed with `memset(tmpBuf, 0, 4)` from `../arm9_sdk/libc/string.h` compiles to the object's `add r1, sp, #0xc` plus four `strb`; four explicit stores, a loop, an initializer and a pointer walk all differ. The include is `"../arm9_sdk/libc/string.h"` (the `../../matched/...` spelling only works from a scratch path).
- **Same call in both if/else arms (DWCi_SceneInit).** `if (Language() == 1 && Flag(2)) n = A; else n = tbl[Language()];` followed by one shared MSGlRead compiles to predicated `ldrne` code. Putting `n = ...; g = MSGlRead(n);` in both arms (with a second Language() call in the else) reproduces the object's `beq ... ldr; b join` shape. Nested if/else, goto, ternary and an inline predicate helper all gave the predicated form.
- **Reverse declaration order swaps registers (MBi_StartParentCore).** With `enabled, cb_tmp, ret, i` declared in the DWARF listing order, enabled and i took each other's registers; declaring `i, ret, cb_tmp, enabled` fixed it. `-1` stored through a `signed char *` gives `mvn r1, #0`; a `u8 *` gives `mov r1, #0xff`.
- **A switch whose first case holds the whole body (WCM_ConnectAsync).** The object dispatches `cmp #3 beq / cmp #8 beq / cmp #9 beq / b default` and places cases 8, 9 and default after the case-3 body and the `b` past it. That comes from `case 3:` containing the entire connect body ending in `break;`, then `case 8`, `case 9`, `default` after it. An early `case 3: break;` with the body after the switch gives 436 bytes.
- **Union alias arms (WCM_ConnectAsync).** `keyId` and `keyLen` share offset 1 in the vendor struct. The object copies 0x50 bytes when `mode <= 3` and `keyLen` bytes otherwise. Writing the `mode > 3` copy size as the just-stored `wcmw->privacyDesc.u.keyLen` avoids a re-read of `wepDesc->keyLen` (a re-read adds an `ldrb` and 4 bytes). A `switch (mode)` here compiles to a jump table and is wrong; use if/else-if.
- **Callback argument position (DWCi_GetReverseBuddiesCallback).** The DWARF lists one parameter, but the object receives it in r1. A leading `void *connection` parameter fixes it. A trailing `if (IsBuddy(...)) SetExp(...)` sits outside the `j == n` test (it runs after every loop exit).
