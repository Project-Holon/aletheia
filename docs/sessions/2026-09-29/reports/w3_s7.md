## Near miss: 0x021986C4 gt2StringToAddress (328 vs 324 B)

Everything matches except register choice for known-zero constants. The prologue
(`mov r4,#0; mov r5,r4`, and the conditional `moveq r5,#0; moveq r4,r5` for the empty-string
path) is reproduced by declaring `u16 srcPort = 0; u32 srcIP = 0;` (port first) plus an
explicit `if (!host || !*host) { srcIP = 0; srcPort = srcIP; }` arm. Residue: the image uses
r5 for `host = NULL` and `stackHost[len] = 0` and r4 for the isdigit `: 0` arm; ours uses r4
for the first two and materialises a fresh `mov r2,#0` for the third (+4 B, then a shift of
every later branch offset). Tried about 25 variants: init order, chained assignment,
`srcIP = srcPort`, initialisers in declarations versus statements, casting srcIP/srcPort into
the zero uses, isdigit written `< 0x80 ? map&8 : 0` versus `>= 0x80 ? 0 : map&8` (the second
fixes the movhs/lsllo order), all identical or worse.

## Levers found

- **Small magic copy through a byte pointer.** The image loads all six bytes of
  NNMagicData first and then stores them off a register holding &p (`add r8, sp, #0x10`), with
  the version/type stores interleaved. Struct assignment, per-field assignment, a helper
  function, memcpy and loops do not give that. This does:

      u8 *m = (u8 *)&g_021A5A7C;
      u8 *d = (u8 *)&p;
      d[0] = m[0]; d[1] = m[1]; ... d[5] = m[5];

  in an inner block before `p.version = ...`. It fixed SendPreinitPacket, SendPingPacket and
  SendReportPacket (all three EXACT). Worth an idiom page.
- Struct passed by value (natneg `nat`, 216 B) to a function pointer: `cb(success, nat)` gives
  the r1..r3 plus `sub sp` stack copy, ldm/stm loop; the struct size must be exact (216 B)
  or the frame differs by 4. CheckNatifyStatus also needed a goto-spelled `done:` exit so the
  early return keeps an unpredicated tail.
- natneg.o addresses several file-scope statics through one anchor literal
  (`negotiateList` 0x021AE698: +8 natMappingScheme, +0xC natifyCallback, +0x10
  natifyStartTime, +0x2C matchup1ip; `natType` 0x021A5A70: +4 ertSock, +8 mappingSock).
  Modelled as one extern struct per anchor; the same variable (matchup1ip) appears once via
  its own literal (g_021AE6C4) and once via the anchor, so both externs are kept.
- gti2HandleConnectionReset: `if (!timeout || elapsed < timeout) return 1;` in one condition
  (the nested form emits predicated returns), and the `return 0/1` shape follows the image.
- gti2DeliverReliableMessage is an if/else-if chain on `type`, not a switch (a switch emits a
  jump table).
- `x != 0` return spelling gives the `movne r0,#1 / moveq r0,#0` pair (gti2HandleClientResponse).
