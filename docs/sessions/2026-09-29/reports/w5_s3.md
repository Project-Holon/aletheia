## Near misses (about 12-15 attempts each)

- 0x021D600C Coord2Rect (compiled 48 B, 17 B differ): object loads x,y (coord) then w,h (size) into lr,ip,r3,r0 before any store, then stores l, adds, stores t,r,b. Compiler interleaves the size loads (x,w,y,h). Tried direct fields, unsigned short/int locals in all 24 declaration orders and 3 store orders, struct copies, `RECT` local plus `*rect = r`.
- 0x021D6B04 TPlCheckATrigger (compiled 96 B, 4 B differ): identical except the compiler loads a->w before a->y (object: x,y,w,h). Locals x,y,w,hh in address order; declaration order, statement order and struct-typed variants (partial permutation search) did not move it.
- 0x021BD744 ICONlInit (compiled 176 B, 14 B differ): only the schedule of four instructions differs: object does `ldr r1,=CN_ICON; str r0,[r4]; ldrb r1,[r1,r5,lsl #2]; mov r6,#0; strb r5,[r0,#8]`, compiler emits `str; ldr r1; strb; ldrb`. Tried type store before/after, temp locals for the icon byte, local `m` pointer, `(type,idx)` comma expression, byte-pointer indexing. CN_ICON indexed with stride 4 (`unsigned char [][4]`), DWARF says `[4][2]`.
- 0x021BD7F4 ICONlEnd (compiled 64 B, 3 B differ): the object loads `&MemIcon` for the `DWCi_HEAPlFree_` argument from a second literal-pool word (`ldr r0,[pc,#8]`), the compiler reuses r4 (`mov r0,r4`). Tried casts, local pointer, typed `MemIcon **` parameter, unsigned cast of the address.
- 0x021C0A2C checkParam (compiled 120 B vs 124 B): object extracts the low 4 bits of `param` as `lsl #28; lsr #28` (compare `hi`, unsigned) then `lsr #4` for the two flag tests; `& 0xF` and `(x<<28)>>28` fold to `and`, bitfield union by value/local spills to the stack. Body otherwise identical.

## Levers and notes

- Verify-time status: the packet name in headers is `pkt_ov016_XXXXXXXX`; callees in the ov016 window carry the `ov016` token, `func_02177EC8/ED8` carry `ov009`, AOSS thumb callees (`AOSSi_Init` 0x021B61D0, `AOSSi_EndLocal` 0x021B85A8) are thumb with `ov016`.
- `switch` (not if/else chain) reproduced the beq-to-shared-literal shape in HLlInit.
- Locals `void *mem; unsigned long irq;` (mem declared first) fixed the register swap in HEAPlAlloc.
- Struct copy `*c = t->a;` with an inverted branch (`if (!t->flag) {*c = t->b; return 0;}`) reproduced TPlGet; the `_ZZ18DWCi_IPTlCheckFoldvE4fold` symbol at 0x021DE688 is a struct `{u8 fold; TpData *tp;}` (pointer at +4 used by TPlGet).
- Word-wise OAM position write `(attr01 & 0xFE00FF00) | y | (x << 16)` and `attr2 = (attr2 & ~0xC00) | 0x800` matched with a union `GXOamAttr`; IME disable/restore as `unsigned short old = *ime; *ime = 0; ... (void)*ime; *ime = old;` matched in taskRenew.
- `*(volatile unsigned int *)((unsigned int)&g_02FE0000 + 0x3FF8) |= 1` matched intrVBlank (a `char *` base plus 0x3000 and index did not).
- Header-status caveat: for EXACT* rows the status text must be copied as `EXACT*` (0x021C0900).
- Two shared statics at 0x021DE564/0x021DE568 in libaoss (a control struct and the pointer at its +4) are declared as two externs.
