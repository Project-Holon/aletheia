## Levers found

- `LOWER(c) ((((c) >= 'A') & ((c) <= 'Z')) ? (c) + 0x20 : (c))` used as `LOWER(c1) != LOWER(c2)` inside an `if`
  matches strnicmp (assigning back into char locals adds lsl/asr truncation and different registers).
- Shared "compute then test" tails: `if (A) { ...; if (full == 0) ret = 1; } else if (full == 0) { ret = 1; }` (BufFull)
  reproduces the trailing `b` + `moveq`; a goto or early returns give different layouts.
- Early-return error tail last: `if (len >= 0) {...; if (len == 0 && state != 4) return 0;} else { *p = -1; return 0; } return buf + consumed;`
  (ReadCPSBuffer) places the second return after the error block.
- `if (flag & 1) x = f(cbA,...); else x = f(cbB,...);` gives the `ldrne/ldreq` pair (ExecReadCommand, EXACT*).
- Two-word global copy/restore (InetAtoH): declare locals hostip, enable, dns0, dns1 (reverse of listing) and copy the two
  words separately; the compiler emits ldm/stm.
- SetResolver: `g[0] = dns1;` before an `if (dns1 == 0) {...} else {...}` (zero arm first) gives the hoisted str.
- Static inline predicate `int r = 1; if (mode != 0 && mode != 4) r = 0; return r;` materialises the `mov r1,#1 ... movne r1,#0` pair (ShutdownCallBack).
- Resolve: stores into the stack struct in image order (buf, buf_size, work_end, work) fix the str order; the 0xb68 constant is
  derived by the compiler from the 0x1708 pool word (`sub r3,r6,#0xba0`), write it as 0xb68.
- SaveBuf: keep a copy `len = srclen` as the loop counter and `return srclen`; a guard `if (srclen > 0)` in front of the loop
  reproduces the extra compare.
