## Levers that worked

- Switches over a WM result code with a jump table: the table needs every index 0..N present as explicit cases
  (`case 0: case 1: ... default:`); find the real case from the table entries (WCMi_WmifStartupAsync: case 0 continues,
  case 3 and default share the failure arm, case 4 returns 5). Continuing arm placed last in source (`case 0: break;`
  after default).
- Non-encodable constants (0x4b7, 0x519, 0x4fa) are folded by the compiler into `rsb/add rX, rN, #imm` against a live
  constant register; write the plain constant.
- `maxScanTime` style select: `t = f->x; if (t == 0) t = call(); dst = t;` (not a ternary, not if/else stores).
- Two-arm copy with different source (WcmEditScanExParam bssid): call MI_CpuCopy8 in both if/else arms; the ternary
  and the local `src` forms compile to a conditional ldr instead.
- 1 << x >> 1 stored to a u16 field: no cast on the intermediate.
- Structs with pad arrays to model WCMWork offsets (0x12DE phase, 0x22A0 scan param) verified against three functions.

## Near misses

- WCM_InitEx 0x02164D74 (364 B, same size, all instructions equal): only the scheduling of the first block differs at
  +0x18..+0x28. Original emits `ldr sb,[pool]` before `mov r1,#0` and `str r1,[sp]` after `mov r5,r0`; ours emits
  `mov r1,#0`, `ldr sb`, `str r1,[sp]`. Tried: expectLen zeroed before/after Disable, at declaration, after the first if,
  local declaration order swapped, `if (g.wcmw)`, two separate externs for the pair (worse, 400 B). The global is one
  pool word (struct {u8 overridedDeviceId; WCMWork *wcmw;} at 0x021AA7D4); ABS32 named WCMi_OverridedDeviceId only.
- SSP_JpegEncoderResample 0x021C1D8C (376 B original, 388 B ours): identical instruction selection, register
  allocation differs. Original: src r6, dst fp, src16 base sb, dst16 base r8, row offset r7, ofs lr, y/u/v in r0/r3/ip,
  one spill set at sp+8 (srcWidth<<4), sp+0xc (dstWidth-1), sp+0x10 loopDstH, sp+0x14 step. Ours spills dst and puts
  y/u/v in r7/sl/r8. Tried: block-scoped y/u/v and ofs, index not held in u, arm order swapped, declaration order forward,
  reversed and rotated, `fmt == 0x100` only (376 B but drops the redundant `cmp r5,#4` that the original has).
  The original keeps the redundant `fmt == 4 || fmt != 0x100` test. Next idea: source likely declares typed u16/u32
  pointer locals that DWARF omits, or uses macros; try explicit `unsigned short *` row pointers.
