## Levers found

- A struct member typed as byte-only aggregate gives the alignment-1 pair copy loop (ldrb/ldrb/strb/strb x N): `SOCSockAddrIn` with `unsigned char port[2]; unsigned char addr[4]` matched StartReport 0x021994F0 where the u16/u32 layout gave word copies.
- Defeating load CSE: `localip = *(unsigned int *)addr;` while testing `addr->addr` (GetLocalIP 0x021988F4/0x021992FC) keeps the compare value in a scratch register; using `addr->addr` for both merges them into a callee-saved register.
- `if (hent == 0) return 0; return ...` and `if (!a || !b || !c) return 0; return 1;` give the original conditional-move order where `!hent` and `&&` chains did not (NameToIp, ResolveServers).
- Two adjacent cases `case 0: case 1: return; case 2: call` reproduce cmp/cmpne/cmp chains that `||` folds into a single `cmp #1; ls` (ProcessPreinitAckPacket).
- Stack-slot order again follows the reverse of the DWARF variable listing (handle_public_address 0x0219BB54).
- Both `if (a) x = p->f; else x = 0;` (separate reloads of the base pointer per arm, sakeiExecuteRequest) and `return rcode < 0` then `return 1` (not `return rcode >= 0`) matter for conditional-execute order.
