### func_02066998: NitroSystem cell-transfer manager update
- **Identity:** this is NitroSystem code. g_02148B20 is the manager block `{ pFuncTransfer, numState, pStateArray }`. Each 0x30-byte cell is an NNSG2dCellTransferState. func_020640D4 is NNSi_G2dGetVramLocation, and tbl_020A1808 maps VRAM type to GFD transfer type.
- **Lever 1:** the VRAM-type loop variable is an enum bounded by its _MAX value. This alone keeps the dead `cmp r7,#3 / bge` entry test. Every int, short or char counter folds it away.
- **Lever 2:** tbl_020A1808 is declared non-const. A const table load sinks past the call, which frees a register. With the table load before the call, the i/off stack spills appear naturally, so the old volatile counters are not needed.
- **Lever 3:** ShouldTransfer is one inline returning `a && b`.
- **Lever 4:** the type variable is declared at function scope next to i.
