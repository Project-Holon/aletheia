## Lesson worth spreading
When a residue is a clean register swap and the permuter is flat, move each local between block
scope and function scope. It worked in both directions this wave:
- Per-arm locals closed 02064934, 02064754 and 02064B68.
- Function-scope sharing took 020643CC from 31 to 7.
permuter.py's decl-order mutation only reorders declarations and never moves one to another scope,
so this search is outside what the permuter can do.
