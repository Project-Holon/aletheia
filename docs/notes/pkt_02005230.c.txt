wave r8 lane small-1: the label-capped rows of this lane
========================================================

This note carries the rows whose verdict is "parked, class label" - the C is
already written and byte-correct, every site's target is a cut-free call whose
only branch image-wide is the call inside the parked function.  The rows live
in six different packets; the two of this file's own packet come first and the
rest are cross-referenced with the packet their park header names.
