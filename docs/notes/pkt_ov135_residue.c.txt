1. IF-CONVERSION IS WHAT BREAKS THE TWO-ARM SHAPE.  `n = (f() == 1) ? 0 : 1`,

   32.  No -O level changes it (the transform lives in the code generator, not
   the optimiser): -O4,p, -O4,s, -O4, -O3, -O2 and -O1 all emit the same bytes.

   constant select, the arms are not pure assignments in the source.

   `(p + n - 1) / n`, and the divide is the two-argument helper at 0x0209C0A4

   unsigned divmod in asm/arm9/main.s).  With a one-argument call the compiler
   folds the offset into r1 (`subs r1,r1,#1; adds r0,r0,r1`); with the divisor

   image uses is the fix: `extern u32 func_0209C0A4(u32 a, u32 b);`.
