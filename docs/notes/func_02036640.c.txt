WHAT IT IS
----------
Distance from the +4 cursor to a wrapped marker: when the +0xc signed half has
passed the +0xe one, the +0xe value is measured from the end of the buffer
(+4) instead.

    int func_02036640(struct Obj *o)
    {
        return (int)o->f4 -
               ((o->fc > o->fe ? (int)o->f4 + o->fe : o->fe) - o->fc);
    }

The control flow, the predicated arms and the shared `sub r1, r1, r3` /
`sub r0, r0, r1` tail are all right; the original shares the tail exactly this
way.

conditional.  The CSE happens on the load, not on the expression, so the
