The body is a multi-word subtract with carry, spelled in the original as a
64-bit add that keeps its high half as the borrow:

  021CDB9C  push {r4, r5, r6, r7, lr}
  021CDBA0  mov  r7, r0                ; dst

  021CDBA8  mov  r0, #0                ; borrow = 0
  021CDBAC  poplt {r4, r5, r6, r7, pc}

  021CDBC0  adc  r0, lr, #0            ; borrow = high word

The `adds`/`adc zero` pair is the 64-bit-add high-word tell, see
docs/idioms/a-64-bit-add-high-word-is-adc-zero.md; the 32-bit form
`borrow = (z < x)` compiles to cmp/movhi/movls instead.

Closest source (72 bytes, 53 mismatches):
