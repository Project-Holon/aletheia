WHY NO SOURCE FILE WAS WRITTEN
------------------------------
Matchable C would have to reproduce all 3836 code bytes of dwc_match.c
(the Debug DWARF puts the function at decl_file 383 = dwc_match.c line 1956,
running to ~line 2600, with locals fullSpec/resendInterval/sbInterval/result/
sbError and block locals node/mc/idx/pNodeInfo/i/noResponseHosts/info/
connection).  That is SDK library code, ~950 instructions of an unrolled
twelve-state match state machine, whose source is not in the tree (only the
seven SDK headers under sdk/TwlDWC/include/match).  Hand-matching it would be
a multi-session project for zero game coverage; the honest record is this
note plus the recommendation below.
