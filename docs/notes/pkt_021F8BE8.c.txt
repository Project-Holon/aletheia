worldtrade connect flow. Best source: src/pending/ov/ov135_func_021F8BE8.c

Everything matches except one hop. In the image the inner switch on the
sub-state (p+0xF80, cases 0..3, jump table) sends its out-of-range value to
0x021F8C90, which is a lone "b 0x021F8CEC" (the shared func_021F513C(p);
return 0 tail). Our build threads that bhi straight to the tail, so the
table and every later pc-relative load shift by 2 bytes.
