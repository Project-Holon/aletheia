The friend-list lookup in the DWC wrapper file: build a friend-key token
from (a1, a2), compare its GS profile id against every entry of the 0xC-byte
friend record array, report the matching slot through *out.  Returns 3 if
the key is bad or the token has no profile id, 0 on a hit, 2 if the list was
walked without one; *out is left holding the first slot whose record fails
DWC_IsValidFriendData when there is no hit, and -1 when there is not even a
free one.

    record stride is written out in this function, so sub_020099C8 is called
