Two things that decided nearly every closure:

  * mwcc hoists the *initial* value of the returned local.  When the image
    opens with `mov r0, #0` (or `#1`) and only later reaches a conditional
    value, the source wrote the result into a local and returned the local:
    `int r = 0; if (p && *p == 1) r = 1; return r;`.  The direct spelling
    `if (p && *p == 1) return 1; return 0;` compiles to `moveq r0, #1;
    bxeq lr` and never matches.  This flipped 02168D7C, 0216AA70 and
    0216C82C from DIFF to EXACT in one compile each, and the same shape is
    what 0215F080/0216B634 needed.

  * `scratch/ov009/f2.json` (and every classifier built on it) DROPS `.inst`
    lines.  The listing emits an out-of-region `bl` as `.inst 0xEB...` with
    the target only in the trailing comment, so a function that calls
    out-of-region reads as a leaf there.  0216909C cost one compile that
    way: the body has an unnoticed `bl 0x020870D0` whose result is stored.
    Parse asm/overlays/ov009.s directly (scratch/ov009/o26/listing.py) when
    counting calls.
