THE LEVER IS `r = !!q;`.  The note above lists fourteen spellings of the first
guard's false arm, every one of which either hoists the zero above the
`cmp r2, #0` or lets 2.0 forward the provably-zero r2 as `moveq r0, r2`.  The
double negation does neither:

    q = *(int *)(o + 0xc);
    r = !!q;
    if (r == 0) return;

gives the image's `cmp r2, #0` / `movne r0, #1` / `moveq r0, #0` triple at
0x02064240..0x02064248 exactly, at the original's 240 bytes, 0 concrete
mismatches, under ../2.0/sp2.  Read it as: `!!q` is two boolean conversions,
so the compiler materialises the result from immediates in both arms rather
than reasoning about what q holds in the eq arm.  `(q != 0)` alone is NOT the
same thing -- it is the `r = (q != 0);` spelling and it restructures the
whole tail (five instructions out).

Everything else in the note's C is unchanged, including the `char *o;`-before-
`int kind;` declaration order and the `*(volatile int *)` read of the +0x38
sentinel.
