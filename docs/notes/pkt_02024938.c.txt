Two things differ and both are spelling, not reading:
  - the +1 must be a SYMBOL (a second extern at 0x0209F785), because `ldrb`
    with a register offset has no immediate and this compiler otherwise folds
    +1 into an immediate off the already-indexed base (`ldrb r0, [r1, #1]`),
    which is four bytes shorter;

    second loop has to be a u32 separate from the `int` counters of the first
