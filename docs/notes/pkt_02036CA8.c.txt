Ruled out (all reproduce the same 160-byte code with the roles swapped):

  - declaring the mask before the value, and assigning the mask before the
    value in each arm;
  - declaring the switch value as a third local and switching on it;
  - `v &= 0x00300010;` as a separate statement (this one merges the loads and
    lands at 148 bytes, i.e. it is a different program);
  - non-volatile reads (the compiler then merges the two loads).
