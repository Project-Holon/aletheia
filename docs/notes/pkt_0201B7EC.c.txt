The second error is the shape of the test.  `(v >> 31) & 1` on a bare
temporary folds to a single `lsrs`, but the original materialises a zero and
shifts it:

    movs r1, #0        <- a zero that survives
    lsrs r0, r0, #0x1f
    lsls r1, r1, #1    <- shifted, though it is provably still zero
    orrs r1, r0
    movs r0, #1
    tst  r0, r1

That is a ONE-BIT ACCUMULATOR, `m = (m << 1) | bit`, written as separate
statements.  It has to be separate statements: written as one expression the
compiler folds the whole thing and the four instructions collapse.  And the
zero has to be assigned AFTER the call -- assigned before it, `m` is live
across the `blx`, takes a callee-saved register and the prologue grows to
`push {r3, r4, r5, r6, r7, lr}`.  Measured, at size 44/44 throughout:
