Ruled out: keeping the field in a named u32 f used by both test conditions and
the merge expression (that compiles to 388 bytes and makes the register

three (three plain `u32 a = b = c = 0` locals is what reproduces the
mov r3,#0; mov r2,r3; mov r1,r3 zero-block).
