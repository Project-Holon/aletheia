## Harness notes worth carrying forward

- `--flags` needs the `=` form: `--flags=-O4,p`.  A separate argument is parsed as an option.
- A long source path breaks mwcc ("Specified file ... not found"): the parked filename
  `v_ov016_func_021D0DE0.c` under `scratch/laneU10/` fails, `cbv.c` in the same directory works.
- A header without a `symbols:` block is refused with `ISA conflict for <callee>`, before any
  comparison, even when the callee's own ISA is the one the image has.
