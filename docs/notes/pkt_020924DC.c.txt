packed descriptor, and the function writes a formatted string into the buffer
at r8.  Frames: push {r4-r8, sb, sl, fp, lr}, sub sp, #0x4c, so incoming
stack arguments start at sp+0x70 and the descriptor fields the function reads
are stack words: r6 = *(u32*)(sp+0x88) (a bound, compared against 0x1FD from
the pool, `ble`-style early `return 0` at 0x02092F48), r5 = *(u8*)(sp+0x81),
fp = *(u8*)(sp+0x7f), r4 = *(u8*)(sp+0x7d), and two more words moved to
sp+8 and sp+0xc.

  0x02092F5C-0x02092F98  build the descriptor at sp+0x10 (strb 0, strh 0x20)
      and call func_020972F0(sp+0x10, word, word, sp+0x14); the conversion
      character comes back in *(u8*)(sp+0x19) and is switched on three ways:
      '0' (0x30) -> one branch, 'I' (0x49) -> 0x02092FA4, 'N' (0x4E) ->
      0x020930A8, default 0x020931AC.
  0x02092FA4-0x020930A4  the 'I' path: *(u8*)(sp+0x14) selects between
      "value was parsed" and not; r5 == 0x41 ('A') selects upper case; each
      leaf writes a five-byte record from a table (0x020A8A40/48/50/54) over

      ldrb/strb pairs, not a memcpy, so the source indexed a `u8[5]` by hand.
  0x020930A8-0x020931A8  the 'N' path: the same table-copy shape with
      0x020A8A58/60/68/6C.
  0x020931AC-0x0209338C  the general path: build a small record at
      sp+0x3c (bytes 1,1,0,0,0, 0x64, words 0 and 1), reverse the four bytes
      at sp+0x70, extract a 5-5-? field pair from sp+0x70/0x71

WHERE THE DIFFICULTY IS.  Three quarters of the function is byte-level work
on `b`-sized fields and five-byte records: dozens of `strb`/`ldrb` pairs with
`sub`-based field widths (5 bytes vs 4 bytes chosen by the case), a reversed
loop over a four-byte scratch buffer, and one 5-5-5 style bit extraction.
None of that is impossible, but each field is a separate declaration choice
(u8 vs s8 vs a bitfield), and the register allocation of a 288-instruction
frame-using ARM function with eight callee-saved registers is decided
globally, so a body has to be written whole before any of it can be judged.

That is why this note stops at the map: the honest trade was to spend the run
on the packet's 1744-byte function, where the same effort produced a
measurable near miss.
