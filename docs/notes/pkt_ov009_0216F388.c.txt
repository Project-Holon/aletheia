DWCi_ResetMatchParam (ov009 0x0216F388, libdwcmatch.TWL.HYB.a dwc_match.o, 628 bytes)

The function is a long run of zero stores into the DWCi_GetMatchCnt() control
block, plus two level-dependent tails. Every field offset and every stored
value is recovered; the whole body is known.

Residue: the original calls DWCi_GetMatchCnt() ONCE for a *group* of adjacent
word/byte stores and reuses the base register, e.g.

  000C bl GetMatchCnt; mov r4,#0
  0010 strb r4,[r0,#0xc]
  0014 bl GetMatchCnt            <- one call ...
  0018 strb r4,[r0,#0x5f8]
  001C bl GetMatchCnt            <- ... per 1-3 field group
  003C bl GetMatchCnt
  0040 str r4,[r0,#0x600]
  0044 str r4,[r0,#0x604]        <- two stores, one call
  0048 bl GetMatchCnt
  004C str r4,[r0,#0x608]
  0050 str r4,[r0,#0x60c]        <- two stores, one call
  ...
  0144 str r4,[r0,#0x638]
  0148 str r4,[r0,#0x63c]
  014c str r4,[r0,#0x640]        <- three stores, one call (0x638 group)

Writing the natural `DWCi_GetMatchCnt()->f = 0;` per field gives one call per
store (656 bytes, 70 relocations vs the original 628 bytes), so the grouping
is a source-level construct, not a compiler CSE of the getter (the same getter
is NOT CSE'd in DWCi_RestartFromCancel 0x02172BB8, which matched EXACT). The
groups look like aggregate stores: an 8-byte zero blob for the pairs
(0x600/0x604, 0x608/0x60c, 0x658/0x65c, 0x668/0x66c, 0x670/0x674, 0x648/0x64c)
and a 12-byte blob for 0x638/0x63c/0x640. A `= (struct T){0}` / compound
literal spelling of exactly those groups would very likely restore the bytes;
the pair/triple boundaries are not recoverable from the instruction stream
alone because all three forms produce identical stores.

Related: DWCi_RestartFromCancel (same object) matched EXACT and is a good
worked example of the same getter used once per source call. The three
`b = DWCi_GetMatchCnt()->f680 == 0;` temporaries there are load-bearing: with
the boolean inlined as the callback's 3rd argument, mwc emits the getter for
the call target before the argument and the body diverges.
