  if (bpp == 4)          ->  32-bit mask arm, one word per row
  else                   ->  64-bit mask arm, two words per row, with the
                             >= 32 shift cases spelled out longhand

The masks are built from the first/last pixel columns:

  u = x << 2 (or << 3);  v = 0x20 (or 0x40) - (u + (w << 2 or 3));
  lo = (~0u >> u) << (v + (x << 2));           /* 4bpp */
  mlo = val & (lo >> v);  mhi = ~(lo >> v);

The 8bpp arm needs the two halves of a 64-bit mask, and the image writes
both >= 32 corrections out as a branch over a four-instruction block:

  cmp r3, #0x20 / lsllo r5, r5, r1 / blo .. / sub lr,r3,#0x20 /
  add r4,r1,lr / lsl r4,r5,r4 / lsr r5,r4,lr

The `else` arm reads the still-undefined destination register
(`add r1, lr, r3` with r3 stale); spelling that in C as
`(hi >> (e + mhi)) << e`, reading the uninitialised `mhi`, is what
reproduces the instruction.  It is deliberate, not an accident.
