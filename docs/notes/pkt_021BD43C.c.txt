The source was always right: `void func_021BD43C(void) { func_021BD404(); }`
tail-calls the thumb function through the pool word and the compiler emits the
thumb-bit-set address 0x021BD405.  match.py's ABS32 label class wrote the bare
even 0x021BD404 because the target had only a `label` witness and no `symbols:`
line, so the low (thumb) bit was lost.

This is NOT a harness gap.  Declaring the target ISA and owner explicitly

    symbols:
      func_021BD404  0x021BD404  thumb  ov208

makes the same C verify EXACT.  This is exactly
`docs/idioms/a-pooled-tail-call-target-needs-a-thumb-region-symbols-hint.md`;
the earlier note mis-read the wildcard as a tool limitation.
