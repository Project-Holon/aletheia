The object is a linear map, not a pointer table: +0x0 and +0x4 are a low and
a high bound, +0x8 the index, +0xC the denominator.  The whole function is

    s32 f(struct Obj *o)
    {
        if (o->f08 >= o->f0c)
            return o->f04;
        return o->f00 + (o->f04 - o->f00) * o->f08 / o->f0c;
    }

and the one lever that mattered is reading the guard's value as a FIELD, not
as a pointee: `p = (s32 *)o->f04; ... return p[0];` makes the guard's load a
conditionally-executed `ldrge r0, [r0, #4]` into a hoisted unconditional load
and is six bytes out, because the tail then loads `*(s32 *)o->f04` while the
original re-reads `o->f04` from the object pointer that the predicated load
left alone.  The division is `_s32_div_f` (0x0209C0A4, runtime class) and is
declared in the `symbols:` block.
