Bound-via-local spellings (`int n = 0x10;`, `const int n = 0x10;`,
`volatile int n = 0x10;`, `n = 0x10;` + do/while) const-propagate the bound to
the immediate `cmp r4, #0x10` but still rotate, so the trip count being a
constant is not what decides it.

Conclusion: a constant-bound loop that the original left un-rotated (entry test
retained, invariants hoisted only into the preheader *after* that test, and
0x1e4 rematerialised in the body instead of being hoisted) does not appear to
be reachable from C under the pinned -O4,p.  func_0202BAF4 @ 0x0202BAF4, the
next labelled function, has the same non-rotated
`movs r4,#0 ; cmp r4,#0x10 ; bge ; ... ; cmp r4,#0x10 ; blt` shape with
`movs r6,#0x1c` in the body, so the two are probably the same original
translation unit and would have to be explained together.
