The buffer handed to func_0204F720 is `sp + 0x10`, which is the incoming home
area (the row's own `push {r3, lr}` accounts for only 8 of the 16 bytes the
epilogue's `add sp, sp, #0x10` unwinds).  So the entry point is the bare
`push {r0, r1, r2, r3}` at 0x020507A0 - the address-of-a-register-parameter
lowering, i.e. the source hands `&third_argument` on - and the row's address
is four bytes into that prologue.  A compiled function always starts at its
own first byte, so no C reaches this row.

Its sibling at 0x020507D0 in the same listing is the tail-call form of the
same accessor (`ldr ip, [pc]; bx ip`, pool word 0x0204F704) and is not part
of this row either.

Addresses are Black-image addresses.
