Two loads of the guard word, the second predicated on the first being non-zero,
and the pointer the body uses is the SECOND load's value (r3).  The closest
spelling is

    struct Obj { struct Sub * volatile p; };
    void f(struct Obj *o, u32 v) {
        struct Sub *p;
        if (o->p != 0 && (p = o->p)->b2c != 2)
            func_02075BAC((u8 *)p + 0x1c, v << 8);

which reproduces that instruction sequence exactly except that the guard value
lands in r2 instead of r3 (5 bytes, `ldr r2,[r0] ... add r0, r2, #0x1c`).  With a
non-volatile field the compiler CSEs the two loads into one and the function is
four bytes short; with `volatile` and a plain early-return guard the body is
if-converted (`ldrne/movne/strne`) and the popeq disappears.

Rejected spellings, all r2 or worse: local pointer plus one reload; the same with
`(p = o->p)` in the condition; two separate `if (...) return;` guards; a union
member for the null test; a cast struct for the second read; `>= 0` and reversed
operands.  The residue is a register choice made below the source text, see
docs/idioms/a-materialised-shift-temporary-is-not-reachable-from-c-or-from-flags.md;
the file was NOT filed, it is a DIFF, not a MATCH.
