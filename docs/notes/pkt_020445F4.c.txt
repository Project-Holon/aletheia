What the function is
--------------------
De-tile an 8bpp tiled surface into a fresh linear one.  The descriptor is the
same three-u16 shape the rest of this packet uses:

    +0x00  u8 *pixels
    +0x04  u16 f04      tile-grid width
    +0x06  u16 f06      tile-grid height
    +0x08  u16 f08      depth / bytes per texel

The pixel dimensions are NOT `f * 8`.  The image computes each as
`lsl #0xd` then `lsr #0x10`, which is `(u32)(f * 8192) >> 16`, i.e. the
multiply-then-truncate-to-u16 form.  Writing `(u16)(f * 8)` instead compiles
to `lsl #0x13` and is 219 bytes out; the `lsr` (not `asr`) is what forces the
cast to be through `u32`.
