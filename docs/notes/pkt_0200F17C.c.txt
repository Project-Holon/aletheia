Two further things the note's C does not have:

  * the arguments are absolute symbols, not addresses and not numbers.  Every
    argument position loads its value from the pool (`ldr r0, [pc]`), and
    mwccarm writes any literal in 0..255 with `movs`

    pool holds seven words -- 0x0A, 0x0B, 9, 0x0D, 0x72, 0x0E, 0x0F -- and
    all seven are loaded: the 5-call arm takes 0x0A, 0x0B, 9, 0x0D, 0x72, the
    0/5 arm takes 0x0E and the 3/4 arm 0x0F.
  * the function RETURNS INT.  The default arm at 0x0200F214 is
    `movs r0, #0` + `pop {r3, pc}`, which only a `return 0` produces: each
    case is `return <its last call>();` and the switch is followed by
    `return 0;`.  Written as a void function with `break`s the file is four
    bytes short (no `movs r0, #0`).
