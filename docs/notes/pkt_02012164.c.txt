WHAT IT IS
----------
The family's "can this animation still run" predicate.  Three unconditional
calls, then a chain of six guards that all share ONE exit block, then a
released-handle call and a seventh guard.  Returns 1 only if every guard
passes.

THE ONE THING THAT DECIDES THE SIZE
-----------------------------------
Written as a chain of separate `if (...) return 0;` statements it compiles
to 126 bytes against the image's 104 -- each arm gets its own
`movs r0,#0 / pop {r4,pc}`.  The image has exactly TWO epilogues, one at
0x020121C2 (`movs r0,#1`) and one at 0x020121C6 (`movs r0,#0`), so every
failing guard branches to the SAME block and the source is a single
conjunction.  See
docs/idioms/guard-chain-sharing-one-exit-block-is-a-single-conjunction.md.
Rewriting the six guards as one `&&` expression takes it from 126/93-out to
102/4-out in one step.

Note the sixth guard is a NEGATED conjunction, not a plain test: the image
has `blx func_02035390 / cmp r0,#1 / bne +3 / blx func_020353B0 /
cmp r0,#1 / beq exit`, i.e. the pair only fails when BOTH return 1.
