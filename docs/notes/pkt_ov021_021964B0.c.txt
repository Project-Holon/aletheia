RGB555 saturating add: for each of n rows of 16 u16 at p, add q[j] to each 5-bit
channel, clamp to 31, repack r | g<<5 | b<<10.

Best C (closest scheduling), dsi/1.1p1 -O4,p:

    for (i = 0; i < n; i++) {
        u16 *row = p + i * 16;
        for (j = 0; j < 16; j++) {
            u16 c = row[j];
            u16 r = c & 0x1F;
            u16 g = (c & 0x3E0) >> 5;
            u16 b = (c & 0x7C00) >> 10;
            u16 d = q[j];
            u16 rr = r + d, gg = g + d, bb = b + d;
            if (rr > 0x1F) rr = 0x1F;
            if (gg > 0x1F) gg = 0x1F;
            if (bb > 0x1F) bb = 0x1F;
            row[j] = rr + (gg << 5) + (bb << 10);
        }
    }
