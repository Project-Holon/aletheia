THE TWO TAILS ARE DIFFERENT, AND ONE OF THEM IS A LOOP
------------------------------------------------------
Path 1 (`rec->unk_1e == 0`, 0x0204211C) ends:

    0204211C  ldrh r1, [fp]            ; *flags
    02042120  mov r0, #1
    02042124  tst r1, r0, lsl r4       ; bit = dst[(x&7) + ((y&7)<<3)]
    02042128  beq 0x20421f8            ; -> return 0
    0204212C  pop                      ; -> return 1

i.e. `if ((*flags & (1 << bit)) == 0) return 0; return 1;`

The `rec->unk_1c == 1` sub-case (conditional-executed at 0x02042138..0x0204214C,
reached with `beq 0x20421d4`) falls into a *rotated loop* at 0x020421D4:

    020421D4  ldrh r2, [fp]
    020421D8  ldr r0, [pc, #0x34]      ; 0x0000ffff
    020421DC  and r1, r2, #0xff
    020421E0  cmp r2, r0
    020421E4  beq 0x20421f8            ; return 0
    020421E8  cmp r4, r1
    020421EC  bne 0x20421e0            ; <- branch BACK to the 0xffff compare

which is exactly `do { if (*flags == 0xffff) return 0; } while (bit != (*flags & 0xff)); return 1;`
The backward branch to 0x020421E0 is the tell: the same condition is a plain
`tst` in the other path, so the two arms do NOT share a source shape.
