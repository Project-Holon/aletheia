### func_021B96B4 0x021B96B4  DIFF

All relocations resolve (4 of 4) when the table is spelled as an `int` array
cast at the call site.  Two spellings, both filed under this address:

  * `extern void (*func_021DCFD0[])(int); ... func_021DCFD0[1](n);` -- MWCC
    dsi/1.1p1 rejects this with "illegal use of type `void`" ... (the same
    spelling is accepted inside ARM9 sources built with a 1.2 compiler, so
    this is a 1.1p1 front-end wart, worth a note for other lanes).

    -- compiles and diffs only in the constant materialisation: the original
    puts `0x021DD064` straight into r0 (`ldr r0, [pc]; blx func_02086028`),
    every form tried routed it through a callee-saved register and pushed an
    extra register pair.
