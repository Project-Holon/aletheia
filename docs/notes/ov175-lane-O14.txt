4. New idioms (the two that took more than one compile)
-------------------------------------------------------
* A pool-word address that is a bare integer constant gets FOLDED into the
  pool and re-allocated: `u32 *p = (u32 *)0x021E5334; p[5] = ...` compiles to
  `ldr r0, =0x021E5348; ldr r0, [r0]` with the base and value registers
  swapped.  Declaring the address as a DATA SYMBOL fixes both at once:

      extern u32 g_021E5334[];      /* symbols: g_021E5334 0x021E5334 data */
      if (g_021E5334[5] == 0) g_021E5334[5] = 1; else g_021E5334[5] = 0;

  gives exactly `ldr r0, =base; ldr r1, [r0, #0x14]; cmp r1, #0;
  moveq r1, #1; movne r1, #0; str r1, [r0, #0x14]`, and match.py attests the
  pool word with the `sole-ref` class (EXACT).  No spelling of the constant
  reaches the encoding; the struct/array/register/if-else variants all fail.
  The predicate pair moveq r1,#1 / movne r1,#0 comes from an `if/else` that
  assigns both arms, not from `p[5] = (p[5] == 0)` (that hoists the 1).

* ARM `push {r3, lr}` + last-statement call is not always `bl`: with
  -interworking, a tail call to an extern whose ISA the compiler does not
  know becomes the pooled `ldr ip, =fn; bx ip`.  `void f(void) { g(); }` is
  enough -- the argument registers are simply forwarded, so the exact
  signature of the callee never has to be known.  15 of the 30 new functions
  are that shape, and every one closed on the first compile.

* Predicated null chains: one single `if (a && b && p && (v = p->f24))`
  expression yields the whole `cmp/cmpne/ldrne/cmpne/ldrne/cmpne/moveq/
  popeq` run; splitting it into separate `if`s doubles the length (60 vs 48
  bytes on func_021DD328).
