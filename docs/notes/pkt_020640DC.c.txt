pkt_020640DC - DIFF residues (lane 5, 0-64 byte band)
======================================================

Three of this packet's four rows are DIFF, all for the same reason: the
original opens with a *predicated* early return (`bxne lr`) and leaves the
guarded block unpredicated, while mwccarm 1.1p1 if-converts the block
(`ldrheq` / `orreq` / `strheq`) and drops the `bxne lr`, four bytes short.
The predication threshold was measured: a sixth instruction in the block makes
the compiler branch again, so the original's five-instruction block sits just
below the threshold this front end uses.  Every spelling tried (early `return`,
`if (p->mode == 1) { ... }`, an explicit `goto done`, a hoisted mode read, a
spelled-out `p->dirty = (u16)(p->dirty | 8)`) predicates.

`volatile` on the parameter is kept because it fixes a *second* difference:
without it the three stores are scheduled (dirty load, tx, ty, orr, dirty
store) instead of written in source order.

Full write-up: docs/notes/g2d_srt_setters.c.txt (wave before this one; this
note is the packet-named home for the three sources, which rule 2 of the band
brief keeps out of src/pending/).

func_020640DC @ 0x020640DC (36 bytes): DIFF, 21 concrete bytes.
func_02064100 @ 0x02064100 (32 bytes): DIFF, 18 concrete bytes, same cause.
func_02064120 @ 0x02064120 (32 bytes): DIFF, 19 concrete bytes, same cause;
  its two scale words fuse into one `stmib r0, {r1, r2}`.

Not filed anywhere: DIFF.  Verdicts reproduced in lane 5 with

too and is written up in docs/notes/pkt_02064178.c.txt: mwccarm hoists the
pool load of the tail call above the three stores and posts the zero store
after them, 23 concrete bytes.

Removed from src/pending/ by lane 5 (rule 2: DIFF belongs in notes only).

/*
 * function: func_020640DC
 * address:  0x020640DC
 * packet:   pkt_020640DC
 * region:   arm9
 * compiler: 1.1p1
 * flags:    -O4,p
 * lang:     c99
 * isa:      arm
 * status:   DIFF
 *
 * The NNS G2D per-node SRT translate setter.  Four bytes short: the original
 * opens with a *predicated* early return (`bxne lr`) and leaves the guarded
 * block unpredicated, while this compiler if-converts the block
 * (`ldrheq`/`orreq`/`strheq`/`strheq`/`strheq`) and drops the `bxne lr`.
 *
 * The predication threshold was measured: a sixth instruction in the block
 * makes mwcc branch again, so the original's five-instruction block sits below
 * the threshold this front end uses.  Every spelling tried (early `return`,
 * `if (p->mode == 1) { ... }`, an explicit `goto done`, a hoisted mode read,
 * a spelled-out `p->dirty = (u16)(p->dirty | 8)`) predicates.
 *
 * `volatile` on the parameter is kept because it fixes a *second* difference:
 * without it the three stores are scheduled (dirty load, tx, ty, orr, dirty
 * store) instead of written in source order.  With it, the only residue is the
 * missing `bxne lr`.  See docs/notes/g2d_srt_setters.c.txt.
 *
 * Verified with:
 *   python tools/match.py one --src src/pending/func_020640DC.c \
 *       --func func_020640DC --addr 0x020640DC --arm --cc 1.1p1
 */

typedef unsigned short u16;
typedef signed short   s16;
typedef signed int     s32;
typedef unsigned int   u32;

struct Srt020640DC {
    u32 mode;       /* +0x00, 1 = SRT enabled */
    s32 scaleX;     /* +0x04 */
    s32 scaleY;     /* +0x08 */
    s16 tx;         /* +0x0C */
    s16 ty;         /* +0x0E */
    u16 rot;        /* +0x10 */
    u16 dirty;      /* +0x12: bit1 scale, bit2 rotation, bit3 translation */
};

void func_020640DC(volatile struct Srt020640DC *p, s16 x, s16 y)
{
    if (p->mode != 1) {
        return;
    }
    p->dirty |= 8;
    p->tx = x;
    p->ty = y;
}
