twl lane (0x02700000..0x02720000, region twl), 2026-09-27
=================================================================

Goal: drive the DSi `twl` region to 100%.  58 lane functions started parked in
src/pending at status MATCH; 51 now promote EXACT (see the shard at
layout/matched/twl/twl.json, 56 entries).  The 7 still parked are all
byte-correct MATCH capped on ONE unattestable data relocation each; none has a
`--suggest-split` cut (each function is a single section, and the blocker site
is inside it, so the range cannot shrink below itself).

The common, immediate unblocker was a symbols-token bug: every file declared its
ARM callees with the token `code` instead of `arm`.  `SYMBOL_RE` accepts only
`thumb|arm|data`, so a `code` line silently terminated the `symbols:` block and
every following relocation read "not in the symbols: block".  Fixing `code` ->
`arm` (and correcting the ISA hint on `func_02004632`, a Thumb ARM9 function
mis-declared `arm`) took 45 files from MATCH to EXACT or to a single real
blocker.  See docs/idioms/a-code-kind-symbols-token-is-not-arm.md.

Second unblocker, no C change: once a TWL callee is filed EXACT, the `matched`
class attests calls to it even though `label` still refuses them for having no
outside caller.  Five files parked on `data_02701FD8`/`data_02702070`/etc. went
EXACT the moment those callees' shards landed.  So re-run `match.py one` on a
parked MATCH after each promotion wave.
