Recursive MATCH unblocker, overlay blocker targets in 0x021D0000..0x026FFFFF
=============================================================================

Lane scope: find the unresolved targets named as blockers by `src/pending/`
files whose target lies at or above 0x021D0000 and below the twl region
0x02700000, match each target (and its non-SDK deps) bottom-up in the correct
region, then re-verify the blocked file and promote it if it turned EXACT.

in this band (0x021D7B74 alone is covered by eleven overlays), so the
`region:` / `symbols:` hint is what disambiguates; a `show` with no `--region`
resolves to whichever overlay happens to carry a `func_` label first and is
routinely the wrong one.
