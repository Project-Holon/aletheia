1. THE SHARED-EPILOGUE SINK IS CLOSED (func_021BAA1C, 264 B, was 106 B
   out).  The residue was never the returns; it is two source-shape
   changes, each inert alone, and the second is what moves the block:

   a. INVERT THE HEAD PROBE so the MATCH is the else arm:
        if (func_021BA590((const char *)c, q->key) != 0) {
            q = q->next;
            while (q != *head) { ... found = 1; break; ... }
        } else {
            found = 1;
        }
      With the match in the then arm the compiler if-converts the first
      `found = 1` in place (`moveq r5, #1`); inverted, it emits
      `beq loc_021BAA94` and lays the block down immediately before the
      join, which is the image.  `else found = 1;` without braces gives
      the same bytes.

   b. ONE `return 1` AT THE END, and the found path only stores:
        if (found != 0) { q->val = d; }
        else { p = func_021BA820(0x18, 4); ... link ... }
        return 1;
      That is what makes the streq chain end in `beq 0x021BAB1C` and
      leaves a single shared `mov r0, #1; pop` at the end of the
      function.  `return 1;` inside the found arm is compiled to its own
      conditional pop and costs 4 bytes (268 vs 264).

   c. Registers: `found` must be declared before `q` (either
      `n, found, q, p` or `found, n, q, p`).  With `found` last the flag
      lands in r5 and the cursor in r4, the mirror of the image.

   Measured: 7 return/decl shapes (best 75 bytes out), then a 5 decl
   order x 3 tail grid (best 73), then 10 arm-inversion shapes, of which
   2 are EXACT and 4 sit at 12 to 107 bytes.  The winning lever was the
   arm inversion, not the returns: no return shape alone gets below 73.

2. func_021BA88C (252 B) - 3 bytes, ONE instruction, after the test
   inversion.  Inverting the null test (fail path first as an early
   `return 0`, good path out of line at 0x021BA948) fixed the whole
   layout, the same lesson as func_021BE880.  What is left is the test:
   the image has `movs r2, r0` (h's home register is r2, so the
   assignment to h is a move that also sets the flags), the compile
   folds h into r0 and emits `cmp r0, #0`.  Making h live past the first
   `bl` moves the register to a callee-saved r4 and costs 11 bytes with
   a `mov r0, r4` where the image reloads [r6+0x1c].  8 spellings tried
   (int/u32/pointer h, reload vs h at the later call, both arm orders).

3. func_021BA988 (140 B) - 2 bytes.  The sign test loads p+0xc into r0;

4. func_021C00FC (32 B) - 6 bytes, register names only, unchanged from

5. func_021CDAC0 (40 B) - 17 bytes, down from 19.  `while (--n >= 0)`

   post-decrement test (`n-- > 0`) and `for (k = n; k-- > 0; )` all
