4. Tooling gap: same-name func_ labels in two overlays with different ISA
   → "ISA conflict ... the image says thumb (the func_%08X label in
   ovNNN); refusing to resolve the call".

  113 of ov114's 462 function addresses also carry a `func_%08X` label in
  an *earlier* overlay whose listing marks it thumb.  match.py's
  isa_evidence() resolves an overlay label through overlay_label(addr),
  which returns the first region in regions_containing() order and
  ignores the `ov114` region token on the `symbols:` line, so every call
  to one of those addresses is refused even though the ov114 listing
  answers the question directly.  Blocked outright by this, all 6 with
  only that site open:
