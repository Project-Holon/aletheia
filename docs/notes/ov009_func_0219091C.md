# Lane S10 -- gpiProcessSearch (ov009, 0x0219091C, 9460 bytes)

Outcome: NOT closed. The function is a full port of the GameSpy SDK
`gpiProcessSearch` and cannot be reached incrementally -- one global register
allocation + one 0x4d4 stack frame + every branch displacement. What this lane
did produce is the missing *premise*: the exact reference object, its
relocations, its strings, and the recovered DWC deltas.

## 1. The reference is in the vendor library (this is the finding)

`sdk/TwlDWC/lib/gamespy/ARM9-TS/Release/libdwcgsgp.a` member `gpisearch.o`
holds `gpiProcessSearch` with **size 9460** -- the same object the overlay was
linked from. Byte-identical to the image; the only difference is that the
object still carries its relocations.

From that archive member:

* `.rela.text` (389 entries): 310 ARM `BL` (reloc type 1) and 79 absolute-word
  (type 2). Every call target and every literal is named by the linker, so the
  `symbols:` block no longer has to be guessed.
* 84 string literals, each in its own `.data` section, contents recoverable.
* `.debug_info`, `.debug_line`, `.debug_abbrev` for the function.
